# great-pyramid-terrestrial-encoding

Supplementary data and code for the preprint:

**Great Pyramid geometry as a continuous terrestrial encoding of celestial direction**

**Author:** Luca Corrieri  
**Affiliation:** Independent Researcher, Budapest, Hungary

## Contents

- `S1_Data.xlsx` — Numerical inputs and outputs used in the manuscript, including astrometric inputs, adopted model constants, propagated coordinates, and derived quantities for the worked stellar examples.
- `S1_Code.py` — Python script reproducing the astrometric propagation, the Vondrák–Capitaine–Wallace long-term precession-bias transformation, and the monument-ground coordinate calculations used in the manuscript.

## Reproducibility

The code uses only the Python standard library. No proprietary or specialised software is required.

The files in this repository correspond to the supplementary materials cited in the preprint.
